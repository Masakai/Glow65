# チュートリアル: はじめてのプログラム(LED カウンタ)

[English](README.md) | **日本語**

章: **1. LED カウンタ** · [2. 足し算とキャリーフラグ](02-addition.ja.md) · [3. UART](03-uart.ja.md) · [4. キーボードを読む](04-echo.ja.md)

5行の 6502 プログラムを書いて Glow65 に読み込み、LED に 2 進数で数える様子を観察します。以下の内容はすべて Glow65 で実行し、`Tests/Glow65Tests/TutorialTests.swift` のテストで確認しています。

## 1. プログラム

[`counter.s`](counter.s) は、A レジスタに 1 を足し続け、メモリに書き込みます。

```
        lda #$00        ; A = 0
loop:   sta COUNTER     ; A をメモリに書く(COUNTER = $03F0)
        clc             ; 足し算の前にキャリーフラグを消す
        adc #$01        ; A = A + 1
        jmp loop        ; 最初に戻る(ずっと繰り返す)
```

| 命令 | 機械語 | バスで起きること |
|---|---|---|
| `lda #$00` | `A9 00` | 読み出し2回: オペコード、値 0 |
| `sta $03F0` | `8D F0 03` | 読み出し3回(オペコード、アドレスの下位・上位)のあと、**書き込み**1回 |
| `clc` | `18` | 読み出し1回: オペコード |
| `adc #$01` | `69 01` | 読み出し2回 |
| `jmp loop` | `4C 02 03` | 読み出し3回。PC が `$0302` に戻る |

ループ1周は 11 サイクルです。

## 2. コンピュータに入れる

11 バイト `A9 00 8D F0 03 18 69 01 4C 02 03` を、RAM の `$0300` に置きます。`$0300-$03FF` は、自作プログラム用に空けてあります。(`$0200-$027F` はモニタの行入力バッファです。ここに置くと、起動のために打つコマンドで上書きされます。)

**方法 A: バイトを手で入力する。** ツールは要りません。アプリを起動し(`swift run Glow65App`)、**POWER** を上げ、端末をクリックして、次を入力します。

```
E 0300 A9 00 8D F0 03 18 69 01 4C 02 03
L 0300 0308
```

`E` はバイトを書き込みます。`L` は、それを命令として一覧にします(逆アセンブル)。打ち込んだバイトが、意図したプログラムになっているかを確認できます。次のように表示されれば成功です。

```
0300  A9 00     LDA   #$00
0302  8D F0 03  STA   $03F0
0305  18        CLC
0306  69 01     ADC   #$01
0308  4C 02 03  JMP   $0302
```

(`D 0300 030F` なら、同じメモリを生のバイトで表示します。)

**方法 B: アセンブルしてファイルを読み込む。** [cc65](https://cc65.github.io/)(`brew install cc65`)が必要です。結果の `counter.bin` はリポジトリに入っているので、最初のコマンドは省けます。

```bash
Tools/assemble.sh tutorial/counter.s        # tutorial/counter.bin(11 バイト)を作る
swift run Glow65App --load tutorial/counter.bin@0300
```

`--load` は、POWER を入れるたびに、ファイルを RAM に読み込みます。起動後は **File → Load Program…**(⌘O)でも読み込めます。`counter.bin` を選び、アドレスは `0300` のままにします。電源を入れると RAM が消去されるので、先に POWER を入れてください。

## 3. 実行する

モニタで次を入力します。

```
G 0300
```

プロンプトは戻ってきません。プログラムは戻らないので、CPU は今、あなたのループを実行しています。(モニタに戻るには **RESET** を押します。RAM は保たれます。)

1MHz では、このループは1秒間に約 90,000 回まわるので、数える様子は追えません。A の LED がでたらめに見えるのは、パネルがレジスタを1秒間に約 60 回しか読み取らないためです。

## 4. 遅くして観察する

1. **SPEED** を **10 Hz** にします。ループ1周は1秒強になり、バスアクセスが順に表示されます。
2. アドレスバスを見ます。`$0300`、`$0301`、`$0302` と進むので、PC の LED とアドレスの下位の LED が、プログラムの進行に合わせて変わります。
3. **INSTRUCTION AT PC** を見ます。実行している命令が、`0302  8D F0 03  STA $03F0` のように出るので、LED とプログラムを対応づけられます。
4. **SYNC** を見ます。命令の最初のアクセス(オペコードの読み出し)で光ります。
5. **WRITE** を見ます。ループ1周に1回、`sta` のときだけ光ります。そのときアドレスバスは `$03F0`、データバスは A の値を示します。
6. **RUN/STOP** を STOP にし、**STEP MODE** を CYCLE にして、**STEP** を繰り返し押します。1回押すごとに、バスアクセスが1つ進みます。

最初の1周を、アクセスごとに並べます。

| # | アドレス | データ | 読み/書き | SYNC | 命令 |
|---|---|---|---|---|---|
| 1 | `$0300` | `A9` | 読み | ○ | `lda #$00` |
| 2 | `$0301` | `00` | 読み | | |
| 3 | `$0302` | `8D` | 読み | ○ | `sta $03F0` |
| 4 | `$0303` | `F0` | 読み | | |
| 5 | `$0304` | `03` | 読み | | |
| 6 | `$03F0` | `00` | **書き** | | |
| 7 | `$0305` | `18` | 読み | ○ | `clc` |
| 8 | `$0306` | `69` | 読み | ○ | `adc #$01` |
| 9 | `$0307` | `01` | 読み | | |
| 10 | `$0308` | `4C` | 読み | ○ | `jmp $0302` |
| 11 | `$0309` | `02` | 読み | | |
| 12 | `$030A` | `03` | 読み | | |

この表示について、2点を知っておいてください。

- 命令を再生している間、A、X、Y、PC、フラグの LED は、命令を実行する**前**の値を示します。命令が終わると変わります。
- 実際の 6502 では `clc` は 2 サイクルかかり、次のバイトをもう1回(ダミーで)読みます。Glow65 はダミーリードを再現しないので、`clc` のアクセスは1回だけ表示されます。サイクルのカウンタは 2 進みます。

## 5. 結果を見る

**RESET** を押してループを止め、モニタに戻って、次を入力します。

```
D 03F0 03FF
```

行の先頭のバイトが、プログラムが `$03F0` に最後に書いた値です。

## 6. 試してみる

RESET を押し、`E` でバイトを変えて、`L 0300 0308` で結果を確認し、`G 0300` でもう一度実行します。バイトのアドレスは次のとおりです。

```
0300  A9 00        lda #$00
0302  8D F0 03     sta $03F0
0305  18           clc
0306  69 01        adc #$01
0308  4C 02 03     jmp $0302
```

1. **2ずつ増やす。** `E 0307 02` で `adc #$01` が `adc #$02` になります。A の LED は、いちばん下のビットを飛ばします。
2. **別の場所に書く。** `E 0303 F1` で、`sta` の書き込み先が `$03F1` になります。`D 03F0 03FF` で確認します。
3. **減らしていく。** `E 0305 38 E9 01` で、`clc` / `adc #$01` が `sec` / `sbc #$01` に変わります。長さは同じで、向きが逆になります。`L 0300 0308` を見ると、`$0305` と `$0306` が `SEC` と `SBC   #$01` になっています。

慣れたら、`counter.s` を書き換え、`Tools/assemble.sh` をもう一度実行して、新しいファイルを読み込みます。プログラムは、`$0300-$03FF` の 256 バイトに収める必要があります(`ROM/user.cfg` を参照)。
