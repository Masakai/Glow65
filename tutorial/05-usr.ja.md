# チュートリアル 5: BASIC から機械語を呼ぶ(USR)

[English](05-usr.md) | [日本語](05-usr.ja.md) &nbsp;·&nbsp; [← 4. キーボードを読む](04-echo.ja.md) &nbsp;·&nbsp; [6. 割り込み →](06-interrupts.ja.md)

BASIC は、書くのは楽で、動きは遅い言語です。機械語は、その逆です。BASIC の `USR` 関数を使うと、両方のいいところが使えます。プログラムは BASIC で書き、必要なところだけ、機械語のルーチンを呼びます。この章のルーチンは、数を2倍にします。以下の内容はすべて Glow65 で実行し、`Tests/Glow65Tests/TutorialUSRTests.swift` で確認しています。

## 1. USR の仕組み

`USR(X)` は、次の3つのことをします。

1. BASIC が `X` を計算し、**FAC**(浮動小数点のアキュムレータ)に置きます。
2. BASIC が、ゼロページの **USR ベクタ**に飛びます。10 番地(`$0A`)にある `JMP` 命令です。続く 11 番地と 12 番地の2バイトが、飛び先のアドレスです。
3. 機械語のルーチンが `rts` で終わると、BASIC は、そのとき FAC にある値を、`USR(X)` の値として受け取ります。

ベクタは、自分の目で見られます。BASIC を起動した直後に、次を実行します。

```
PRINT PEEK(10);PEEK(11);PEEK(12)
 76  219  207
```

76 は `$4C` で、`JMP` のオペコードです。219 と 207 は、`$CFDB` の下位と上位で、BASIC の中のエラー処理です。そのため、この時点で `PRINT USR(21)` を実行すると、`?ILLEGAL QUANTITY ERROR` になります。自分のルーチンを使うには、**そのアドレスを 11 番地(下位)と 12 番地(上位)に POKE** します。

FAC は浮動小数点の数なので、機械語では扱いにくいものです。BASIC は、ゼロページのベクタ経由で、2つの補助ルーチンを用意しています。

| ベクタ | 指す先 | 働き |
|---|---|---|
| `$06-$07` | AYINT | FAC → 16 ビットの符号付き整数。上位バイトが `FACMO`(`$B4`)、下位バイトが `FACLO`(`$B5`) |
| `$08-$09` | GIVAYF | 16 ビットの符号付き整数(A = 上位バイト、Y = 下位バイト)→ FAC |

## 2. プログラム

[`usr_double.s`](usr_double.s):

```
        jsr to_integer  ; 引数が整数になって、FACMO:FACLO に入る
        asl FACLO       ; 下位バイトを左にずらす。bit7 がキャリーに入る
        rol FACMO       ; キャリーを上位バイトに回し入れる: 16 ビットの X * 2
        lda FACMO       ; A = 上位バイト
        ldy FACLO       ; Y = 下位バイト
        jsr to_fac      ; 整数を FAC に戻す
        rts

to_integer:
        jmp (ADRAYI)
to_fac: jmp (ADRGAY)
```

- `jsr` はベクタ経由では飛べませんが、`jmp (ベクタ)` は飛べます。そこで、`jsr` で小さな中継(スタブ)を呼び、スタブが `jmp (ADRAYI)` をします。BASIC のルーチンが `rts` で終わると、あなたの `jsr` の次の命令に戻ります。
- `asl FACLO` と `rol FACMO` は、16 ビットの左シフトで、数を2倍にします。第2章のキャリーと同じ考え方です。

## 3. 読み込む

ルーチンは、これまでと同じ `$0300` に置きます。BASIC は、自分のプログラムと変数を `$0400` から先に置くので、`$0300-$03F7` には触れません。先にファイルを読み込み、そのあと BASIC を起動します。

```bash
swift run Glow65App --load tutorial/usr_double.bin@0300
```

**POWER** を入れ、モニタで `B` と入力して、BASIC を起動します。2つの質問は、Return で進みます。(先にモニタで 21 バイトを入力する方法もあります。`E 0300 20 0F 03 06 B5 26 B4 A5 B4 A4 B5 20 12 03 60 6C 06 00 6C 08 00`、確認に `L 0300 0313`、そのあと `B` です。)

`L 0300 0313` は次のように表示します。

```
0300  20 0F 03  JSR   $030F
0303  06 B5     ASL   $B5
0305  26 B4     ROL   $B4
0307  A5 B4     LDA   $B4
0309  A4 B5     LDY   $B5
030B  20 12 03  JSR   $0312
030E  60        RTS
030F  6C 06 00  JMP   ($0006)
0312  6C 08 00  JMP   ($0008)
```

## 4. 呼ぶ

ルーチンの場所を BASIC に教えます。`$0300` は 768 なので、下位バイトが 0、上位バイトが 3 です。

```
POKE 11,0:POKE 12,3
PRINT USR(21)
 42
PRINT USR(1000)
 2000
PRINT USR(-5)
-10
```

プログラムの中でも使えます。

```
FOR I=1 TO 5:PRINT USR(I);:NEXT
 2  4  6  8  10
```

BASIC が、自分のループから、あなたのルーチンを呼んでいます。なお、BASIC は起動のたびに、ベクタをエラー処理に戻します。BASIC を起動し直したとき(RESET を押して `B` を入力したときも)は、もう一度 11 番地と 12 番地に POKE してください。

## 5. ルーチンの限界

整数は、-32768 から 32767 までの 16 ビットの符号付きで、`asl` と `rol` は、ビットをずらすだけです。

```
PRINT USR(16383)
 32766
PRINT USR(16384)
-32768
PRINT USR(20000)
-25536
```

`16384 × 2 = 32768` は収まらず、最上位ビットが符号になって、結果が負になります。機械語のルーチンは、命令に書いたとおりに動くだけで、範囲を確かめてはくれません。

## 6. 機械語から文字を出す

[`usr_hello.s`](usr_hello.s)(37 バイト)は、第3章と同じように、モニタの `CHROUT`(`$F003`)でメッセージを送ります。引数は使わず、FAC にも触れません。同じ方法で読み込み(`--load tutorial/usr_hello.bin@0300`、または `E 0300 A2 00 BD 0F 03 F0 07 20 03 F0 E8 4C 02 03 60` と、メッセージの `E 030F 48 45 4C 4C 4F 20 46 52 4F 4D 20 41 53 53 45 4D 42 4C 59 0D 0A 00`)、次を実行します。

```
POKE 11,0:POKE 12,3
A=USR(0)
HELLO FROM ASSEMBLY
10 FOR I=1 TO 3:A=USR(0):NEXT
RUN
HELLO FROM ASSEMBLY
HELLO FROM ASSEMBLY
HELLO FROM ASSEMBLY
```

`A=USR(0)` は、結果が要らないルーチンを呼ぶときの、ふつうの書き方です。

## 7. 試してみる

先に、`usr_double` を読み込み直します。

1. **2倍ではなく、半分にする。** `$0303-$0306` の4バイト(`asl $B5` / `rol $B4`)を、`lsr $B4` / `ror $B5`(`46 B4 66 B5`)に替えます。BASIC の `POKE` なら、771 から 774 番地です。

   ```
   POKE 771,70:POKE 772,180:POKE 773,102:POKE 774,181
   PRINT USR(42)
    21
   ```

   ルーチンは RAM にあるので、BASIC から書き換えられます。`lsr` は上位バイトを右にずらし、bit0 をキャリーに入れます。`ror` はそのキャリーを、下位バイトの最上位ビットに回し入れます。
2. **限界を探す。** `PRINT USR(32767)` は `-2` になります(2倍した 65534 が、一周して戻ります)。`PRINT USR(40000)` は `?ILLEGAL QUANTITY ERROR` です。引数そのものが -32768 から 32767 の外なので、最初の補助ルーチン(FAC → 整数)が、ルーチンが数を使う前に、エラーにします。
3. **100 を足す。** シフトを足し算に替えます。`clc`、`lda FACLO`、`adc #100`、`sta FACLO` と書き、キャリーを `FACMO` に足します(`inc FACMO` を `bcc` で飛び越す)。ルーチンが長くなるので、新しい `.s` ファイルに書き、`Tools/assemble.sh` でアセンブルして、新しい `.bin` を読み込みます。

## 8. 覚えておくこと

- ルーチンは、`$0300-$03F7` を自由に使えます。FAC と、BASIC のほかのゼロページは、BASIC が期待するとおりにだけ使ってください。BASIC は、ゼロページのほとんどを使っているので、ほかのゼロページのアドレスは避けます。
- `USR` で呼ばれるルーチンは、`rts` で終わる必要があります。
- 機械語から、モニタのルーチンも呼べます(`$F003` の `CHROUT`、`$F00C` の `GETKEY`)。
