# GAME65G のプログラム例

[English](README.md)

Glow65 の ROM に入っている GAME 言語のインタプリタ [GAME65G](../GAME65G.ja.md) 用に、GAME 言語で書いたプログラムです。

| ファイル | 内容 |
|---|---|
| [startrek.gam](startrek.gam) | Star Trek: 8x8 の銀河に散らばったクリンゴンの戦艦を倒す |

## プログラムの読み込み

GAME65G には LOAD がありません。プログラムは、端末に打ち込んだのと同じ形で送ります。

- **アプリ:** モニタで `T` を入力して GAME65G を起動し、**File → Send Text File…**(⇧⌘O)でファイルを選びます。
- **CLI:** `swift run glow65-cli --input 't\r' --send-text examples/startrek.gam` で、GAME65G を起動してからファイルを送ります。

送り終わったら、`#=1` で実行します。別のプログラムが入っているときは、先に `&=0` で消してください。

## Star Trek

1970 年代のコンピュータゲームにならった Star Trek です。あなたは Enterprise の艦長です。期限までに、銀河にいるクリンゴンの戦艦をすべて倒します。

プログラムは 357 行です。読み込むと `$0600-$3BCF` を使い、ゲームのデータは `$6000-$626F` に置きます。

### 始め方

`#=1` で実行すると、タイトルのあとに `PRESS ANY KEY TO START` と表示されます。キーを待つ間に乱数を回しているので、キーを押した時刻で銀河が決まります。続いて命令が表示されます。クリンゴンの数、期限の宇宙暦、宇宙基地の数です。

### 数値の入力

キーはゲーム自身が読むので、打ち間違えてもプログラムは止まりません。

- 使うのは数字、Backspace、Return です。コースとワープ係数では `.` も使えます。そのほかのキーは無視します。
- Return だけを押すと 0 になります。
- コースとワープ係数は小数第 1 位まで(例 `2.5`)、そのほかは整数で入れます。

### コマンド

`COMMAND (0=HELP)?` に数字を入れます。

| コマンド | 動作 |
|---|---|
| 0 | コマンドの一覧 |
| 1 | 航行(コースとワープ係数を入れる) |
| 2 | 短距離スキャン(いまの象限) |
| 3 | 長距離スキャン(周りの 3x3 の象限) |
| 4 | フェイザーを撃つ |
| 5 | 光子魚雷を撃つ |
| 6 | シールドの操作 |
| 7 | 損傷の報告 |
| 8 | ライブラリコンピュータ |
| 9 | 指揮権を返上する(降参) |

### コース

```
  4  3  2
   \ | /
 5 --*-- 1
   / | \
  6  7  8
```

1 が東(右)、3 が北(上)です。9 は 1 と同じです。小数は 2 つの方向の間を指します。1.5 は東と北東のちょうど中間です。

座標は `X,Y` で表します。X は列(左端が 1)、Y は行(上端が 1)です。象限とセクターのどちらも同じです。

### 航行

- ワープ 1 で 8 セクター、つまり 1 象限進みます。最大はワープ 8.0 です。ワープエンジンが損傷しているときは 0.2 までです。
- 1 回の航行で、(ワープ係数 x 8 + 10)のエネルギーを使います。途中で止まっても同じです。
- ワープ 1 以上の航行は 1 宇宙暦かかります。それより遅い航行は、ワープ係数と同じだけかかります(ワープ 0.5 なら 0.5)。
- 象限の中で進路に何かあると、その手前のセクターでエンジンが止まります。
- 銀河の外には出られません。端で止まります。

### 短距離スキャン

| 記号 | 意味 |
|---|---|
| `<*>` | Enterprise |
| `+K+` | クリンゴンの戦艦 |
| `>!<` | 宇宙基地 |
| ` * ` | 恒星 |
| ` . ` | 何もない |

地図の右に、宇宙暦、状態、象限、セクター、光子魚雷の数、総エネルギー(エネルギーとシールドの合計)、シールド、残りのクリンゴンの数が出ます。状態は DOCKED(ドッキング中)、*RED*(この象限にクリンゴンがいる)、YELLOW(エネルギーが 300 未満)、GREEN のどれかです。

### 長距離スキャン

象限ごとに 3 桁の数字を表示します。左から、クリンゴン、宇宙基地、恒星の数です。`107` は、クリンゴン 1、宇宙基地 0、恒星 7 です。`***` は銀河の外です。見た内容は、コンピュータの銀河の記録に残ります。

### 戦闘

- **フェイザー:** 撃ったエネルギーを、象限にいるクリンゴンで分け合います。損害は距離が遠いほど小さくなります。相手の残りエネルギーの 15% 以下しか当たらないと、損害は出ません。ライブラリコンピュータが損傷していると、狙いが不正確になります。
- **光子魚雷:** 最初は 10 本あります。1 本ごとにエネルギーを 2 使い、指定したコースに飛びます。クリンゴンに当たれば倒し、恒星に当たれば吸収され、宇宙基地に当たれば破壊します。最後の宇宙基地を破壊すると、指揮権を解かれてゲームが終わります。
- **クリンゴンの反撃:** フェイザーか魚雷を撃ったあとと、航行する前に撃ってきます。命中するとシールドが減り、0 未満になると Enterprise は撃沈されます。ドッキング中は撃ってきません。クリンゴンは自分のセクターから動きません。
- **シールド:** コマンド 6 で、エネルギーとシールドの間で配分を変えます。最初のシールドは 0 なので、戦う前に張ってください。

### 損傷と修理

Enterprise には 8 つの装置があります。ワープエンジン、短距離センサー、長距離センサー、フェイザー制御、光子魚雷の発射管、損傷制御、シールド制御、ライブラリコンピュータです。損傷の報告で値が負の装置は、損傷していて使えません。

- 強い攻撃を受けると、装置が損傷することがあります。
- 航行のたびに、装置が損傷したり、修理が進んだりすることがあります。
- 航行すると、損傷した装置がワープ係数の分だけ直ります(1 回の航行で最大 1.0)。
- ドッキング中は、損傷の報告のあとに、まとめて修理するかどうかを聞かれます。修理には最大 0.9 宇宙暦かかります。

### 宇宙基地

宇宙基地の周りの 8 つのセクターのどれかに入ると、ドッキングします。エネルギーが 3000、光子魚雷が 10 本に戻り、シールドは 0 になります。

### ライブラリコンピュータ

`COMPUTER ACTIVE AND AWAITING COMMAND` に数字を入れます(9 で一覧)。

| 番号 | 機能 |
|---|---|
| 0 | 銀河の記録(スキャンで見た象限) |
| 1 | 状態の報告(残りのクリンゴン、残りの期間、宇宙基地の数、損傷の報告) |
| 2 | 光子魚雷のデータ(象限内の各クリンゴンへのコースと距離) |
| 3 | 宇宙基地への航法データ(象限内の宇宙基地へのコースと距離) |
| 4 | 2 つのセクター座標の間のコースと距離の計算 |
| 5 | 銀河の領域名の地図 |

機能 2 で出たコースは、そのまま魚雷のコースに入れられます。

### ゲームの終わり

- **勝ち:** クリンゴンをすべて倒すと勝ちです。効率の評価は、およそ 1000 x(倒したクリンゴンの数 / 使った宇宙暦)の 2 乗です。整数で計算し、上限は 9000 です。
- **負け:** 期限が過ぎる、Enterprise が撃沈される、エネルギーとシールドの合計が 10 以下になる、最後の宇宙基地を破壊する、のどれかです。
- コマンド 9 で降参できます。

終わると `PLAY AGAIN (Y/N)?` と聞かれます。Y で新しい銀河が始まります。

### 補足

- このゲームは、GAME の 26 個の変数をすべて使い、データを `$6000-$626F` に置きます。
- `Tests/Glow65Tests/StarTrekExampleTests.swift` が、決まった銀河での一通りの操作と、反撃、最後の魚雷、ドッキングと修理の場面を確かめています。
- Star Trek は権利者の商標です。このプログラムは、1970 年代のコンピュータゲームにならった非公式のゲームで、権利者とは関係ありません。
