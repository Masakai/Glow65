# 5.1 ロードとストア

[日本語](05-1-load-store.md) | [English](../en/05-1-load-store.md)

[← 5. 命令リファレンス](05-reference.md) &nbsp;·&nbsp; [5.2 レジスタ間の転送 →](05-2-transfer.md)

ロードは、メモリの値をレジスタに入れる命令です。ストアは、レジスタの値をメモリに書く命令です。ロード命令は N と Z を変えます。ストア命令は、フラグを変えません。

この分類の命令は、どれも 8 ビットを 1 つ扱います。16 ビットの値は、2 回に分けて扱います。

<a id="lda"></a>

### LDA(Load Accumulator)ロード A

メモリの値を A に入れます。値に応じて N と Z が変わります。

**影響するフラグ**

<!-- flags:LDA -->
| N | V | D | I | Z | C |
|---|---|---|---|---|---|
| ○ | - | - | - | ○ | - |
<!-- /flags:LDA -->

**オペコード**

<!-- opcodes:LDA -->
| アドレッシングモード | 書き方 | オペコード | バイト数 | サイクル数 |
|---|---|---|---|---|
| イミディエイト | `LDA #$nn` | `$A9` | 2 | 2 |
| ゼロページ | `LDA $nn` | `$A5` | 2 | 3 |
| ゼロページ X | `LDA $nn,X` | `$B5` | 2 | 4 |
| アブソリュート | `LDA $nnnn` | `$AD` | 3 | 4 |
| アブソリュート X | `LDA $nnnn,X` | `$BD` | 3 | 4+ |
| アブソリュート Y | `LDA $nnnn,Y` | `$B9` | 3 | 4+ |
| インデックスト・インダイレクト | `LDA ($nn,X)` | `$A1` | 2 | 6 |
| インダイレクト・インデックスト | `LDA ($nn),Y` | `$B1` | 2 | 5+ |
<!-- /opcodes:LDA -->

**使い方の例**

```
        LDA #$80
```

A が `$80` になります。最上位ビットが 1 なので、N が 1 になります。

```
        LDA #$00
```

A が `$00` になります。値が 0 なので、Z が 1 になります。

<a id="ldx"></a>

### LDX(Load X Register)ロード X

メモリの値を X に入れます。値に応じて N と Z が変わります。インデックスを使うモードは、ゼロページ Y とアブソリュート Y です。

**影響するフラグ**

<!-- flags:LDX -->
| N | V | D | I | Z | C |
|---|---|---|---|---|---|
| ○ | - | - | - | ○ | - |
<!-- /flags:LDX -->

**オペコード**

<!-- opcodes:LDX -->
| アドレッシングモード | 書き方 | オペコード | バイト数 | サイクル数 |
|---|---|---|---|---|
| イミディエイト | `LDX #$nn` | `$A2` | 2 | 2 |
| ゼロページ | `LDX $nn` | `$A6` | 2 | 3 |
| ゼロページ Y | `LDX $nn,Y` | `$B6` | 2 | 4 |
| アブソリュート | `LDX $nnnn` | `$AE` | 3 | 4 |
| アブソリュート Y | `LDX $nnnn,Y` | `$BE` | 3 | 4+ |
<!-- /opcodes:LDX -->

**使い方の例**

```
        LDX #$05
```

X が `$05` になります。

前提: メモリの `$0013` に `$5A` が入っている。

```
        LDY #$03
        LDX $10,Y
```

ゼロページ Y。Y の `$03` を `$10` に足した `$0013` の内容 `$5A` が、X に入ります。

<a id="ldy"></a>

### LDY(Load Y Register)ロード Y

メモリの値を Y に入れます。値に応じて N と Z が変わります。

**影響するフラグ**

<!-- flags:LDY -->
| N | V | D | I | Z | C |
|---|---|---|---|---|---|
| ○ | - | - | - | ○ | - |
<!-- /flags:LDY -->

**オペコード**

<!-- opcodes:LDY -->
| アドレッシングモード | 書き方 | オペコード | バイト数 | サイクル数 |
|---|---|---|---|---|
| イミディエイト | `LDY #$nn` | `$A0` | 2 | 2 |
| ゼロページ | `LDY $nn` | `$A4` | 2 | 3 |
| ゼロページ X | `LDY $nn,X` | `$B4` | 2 | 4 |
| アブソリュート | `LDY $nnnn` | `$AC` | 3 | 4 |
| アブソリュート X | `LDY $nnnn,X` | `$BC` | 3 | 4+ |
<!-- /opcodes:LDY -->

**使い方の例**

```
        LDY #$FF
```

Y が `$FF` になります。最上位ビットが 1 なので、N が 1 になります。

<a id="sta"></a>

### STA(Store Accumulator)ストア A

A の値をメモリに書きます。A もフラグも変わりません。

**影響するフラグ**

<!-- flags:STA -->
| N | V | D | I | Z | C |
|---|---|---|---|---|---|
| - | - | - | - | - | - |
<!-- /flags:STA -->

**オペコード**

<!-- opcodes:STA -->
| アドレッシングモード | 書き方 | オペコード | バイト数 | サイクル数 |
|---|---|---|---|---|
| ゼロページ | `STA $nn` | `$85` | 2 | 3 |
| ゼロページ X | `STA $nn,X` | `$95` | 2 | 4 |
| アブソリュート | `STA $nnnn` | `$8D` | 3 | 4 |
| アブソリュート X | `STA $nnnn,X` | `$9D` | 3 | 5 |
| アブソリュート Y | `STA $nnnn,Y` | `$99` | 3 | 5 |
| インデックスト・インダイレクト | `STA ($nn,X)` | `$81` | 2 | 6 |
| インダイレクト・インデックスト | `STA ($nn),Y` | `$91` | 2 | 6 |
<!-- /opcodes:STA -->

**使い方の例**

前提: メモリの `$0400` に `$00` が入っている。

```
        LDA #$55
        STA $0400
```

`$0400` に A の `$55` が書かれます。

前提: メモリの `$0403` に `$00` が入っている。

```
        LDA #$55
        LDX #$03
        STA $0400,X
```

X の `$03` を `$0400` に足した `$0403` に、`$55` が書かれます。

STA のアブソリュート X と Y、インダイレクト・インデックストは、ページをまたがなくても、またぐ場合と同じサイクル数です。

<a id="stx"></a>

### STX(Store X Register)ストア X

X の値をメモリに書きます。ゼロページ Y のモードがあります。

**影響するフラグ**

<!-- flags:STX -->
| N | V | D | I | Z | C |
|---|---|---|---|---|---|
| - | - | - | - | - | - |
<!-- /flags:STX -->

**オペコード**

<!-- opcodes:STX -->
| アドレッシングモード | 書き方 | オペコード | バイト数 | サイクル数 |
|---|---|---|---|---|
| ゼロページ | `STX $nn` | `$86` | 2 | 3 |
| ゼロページ Y | `STX $nn,Y` | `$96` | 2 | 4 |
| アブソリュート | `STX $nnnn` | `$8E` | 3 | 4 |
<!-- /opcodes:STX -->

**使い方の例**

前提: メモリの `$0010` に `$00` が入っている。

```
        LDX #$07
        STX $10
```

`$0010` に X の `$07` が書かれます。

<a id="sty"></a>

### STY(Store Y Register)ストア Y

Y の値をメモリに書きます。ゼロページ X のモードがあります。

**影響するフラグ**

<!-- flags:STY -->
| N | V | D | I | Z | C |
|---|---|---|---|---|---|
| - | - | - | - | - | - |
<!-- /flags:STY -->

**オペコード**

<!-- opcodes:STY -->
| アドレッシングモード | 書き方 | オペコード | バイト数 | サイクル数 |
|---|---|---|---|---|
| ゼロページ | `STY $nn` | `$84` | 2 | 3 |
| ゼロページ X | `STY $nn,X` | `$94` | 2 | 4 |
| アブソリュート | `STY $nnnn` | `$8C` | 3 | 4 |
<!-- /opcodes:STY -->

**使い方の例**

前提: メモリの `$0400` に `$00` が入っている。

```
        LDY #$09
        STY $0400
```

`$0400` に Y の `$09` が書かれます。

> **Glow65 で確かめられること**
>
> `LDA #$80` のあと、`PHP` と `PLA` で P を A に取り出し、`$03F0` に書きます。
>
> ```
> *E 0300 A9 80 08 68 8D F0 03 60
> *L 0300 0304
> 0300  A9 80     LDA   #$80
> 0302  08        PHP
> 0303  68        PLA
> 0304  8D F0 03  STA   $03F0
> *G 0300
> *D 03F0 03F0
> 03F0: B4 00 00 00 00 00 00 00 24 F4 24 F4 00 00 00 00
> ```
>
> `$B4` は `%10110100` です。N(ビット 7)が 1 になっています。ビット 5 と B(ビット 4)は、PHP が積むときに 1 にします。I(ビット 2)も 1 です。

> **Glow65 で確かめられること**
>
> 3 つのストア命令で、A、X、Y の値を `$03F0` から順に書きます。
>
> ```
> *E 0300 A9 55 A2 07 A0 09 8D F0 03 8E F1 03 8C F2 03 60
> *G 0300
> *D 03F0 03F2
> 03F0: 55 07 09 00 00 00 00 00 24 F4 24 F4 00 00 00 00
> ```
