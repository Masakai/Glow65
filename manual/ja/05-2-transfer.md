# 5.2 レジスタ間の転送

[日本語](05-2-transfer.md) | [English](../en/05-2-transfer.md)

[← 5.1 ロードとストア](05-1-load-store.md) &nbsp;·&nbsp; [5.3 算術演算と比較 →](05-3-arithmetic.md) &nbsp;·&nbsp; [章の入口](05-reference.md)

レジスタの値を、別のレジスタにコピーします。コピー元の値は変わりません。TXS を除いて、N と Z がコピーした値で決まります。

A と X、A と Y、X と SP の間だけ、直接コピーできます。X と Y の間の転送命令はありません。

<a id="tax"></a>

### TAX(Transfer A to X)A を X へ転送

A の値を X にコピーします。N と Z が、コピーした値で決まります。

**影響するフラグ**

<!-- flags:TAX -->
| N | V | D | I | Z | C |
|---|---|---|---|---|---|
| ○ | - | - | - | ○ | - |
<!-- /flags:TAX -->

**オペコード**

<!-- opcodes:TAX -->
| アドレッシングモード | 書き方 | オペコード | バイト数 | サイクル数 |
|---|---|---|---|---|
| インプライド | `TAX` | `$AA` | 1 | 2 |
<!-- /opcodes:TAX -->

**使い方の例**

```
        LDA #$80
        TAX
```

A の `$80` が X にコピーされます。A はそのままで、N が 1 になります。

<a id="tay"></a>

### TAY(Transfer A to Y)A を Y へ転送

A の値を Y にコピーします。N と Z が、コピーした値で決まります。

**影響するフラグ**

<!-- flags:TAY -->
| N | V | D | I | Z | C |
|---|---|---|---|---|---|
| ○ | - | - | - | ○ | - |
<!-- /flags:TAY -->

**オペコード**

<!-- opcodes:TAY -->
| アドレッシングモード | 書き方 | オペコード | バイト数 | サイクル数 |
|---|---|---|---|---|
| インプライド | `TAY` | `$A8` | 1 | 2 |
<!-- /opcodes:TAY -->

**使い方の例**

```
        LDY #$55
        LDA #$00
        TAY
```

Y が `$55` のとき、A の `$00` を Y にコピーすると、Y は `$00` になります。Z が 1 になります。

<a id="txa"></a>

### TXA(Transfer X to A)X を A へ転送

X の値を A にコピーします。N と Z が、コピーした値で決まります。

**影響するフラグ**

<!-- flags:TXA -->
| N | V | D | I | Z | C |
|---|---|---|---|---|---|
| ○ | - | - | - | ○ | - |
<!-- /flags:TXA -->

**オペコード**

<!-- opcodes:TXA -->
| アドレッシングモード | 書き方 | オペコード | バイト数 | サイクル数 |
|---|---|---|---|---|
| インプライド | `TXA` | `$8A` | 1 | 2 |
<!-- /opcodes:TXA -->

**使い方の例**

```
        LDX #$33
        LDA #$00

```

A が `$00` のとき、X の `$33` が A にコピーされます。

### TYA(Transfer Y to A)Y を A へ転送

<a id="tsx"></a>

### TSX(Transfer Stack Pointer to X)SP を X へ転送

SP の値を X にコピーします。N と Z が、コピーした値で決まります。

**影響するフラグ**

<!-- flags:TSX -->
| N | V | D | I | Z | C |
|---|---|---|---|---|---|
| ○ | - | - | - | ○ | - |
<!-- /flags:TSX -->

**オペコード**

<!-- opcodes:TSX -->
| アドレッシングモード | 書き方 | オペコード | バイト数 | サイクル数 |
|---|---|---|---|---|
| インプライド | `TSX` | `$BA` | 1 | 2 |
<!-- /opcodes:TSX -->

**使い方の例**

```
        LDX #$F0
        TXS
        LDX #$00
        TSX
```

SP を `$F0` にして `TSX` で読むと、X は `$F0` になり、N が 1 になります。

SP を書き換えると、スタックの位置が変わります。この例は、実行の前に SP を保存し、終わる前に元へ戻しています。

<a id="txs"></a>

### TXS(Transfer X to Stack Pointer)X を SP へ転送

X の値を SP にコピーします。TXS は、フラグを変えません。

**影響するフラグ**

<!-- flags:TXS -->
| N | V | D | I | Z | C |
|---|---|---|---|---|---|
| - | - | - | - | - | - |
<!-- /flags:TXS -->

**オペコード**

<!-- opcodes:TXS -->
| アドレッシングモード | 書き方 | オペコード | バイト数 | サイクル数 |
|---|---|---|---|---|
| インプライド | `TXS` | `$9A` | 1 | 2 |
<!-- /opcodes:TXS -->

**使い方の例**

```
        LDX #$F0
        LDA #$00
        TXS
```

X が `$F0` でも、直前の `LDA #$00` による Z=1、N=0 が、そのまま残ります。

TXS はフラグを変えません。ほかの転送命令と違う点です。

> **Glow65 で確かめられること**
>
> `LDA #$80` と `TAX`、`LDA #$00` と `TXA` で、A と X の間で値をコピーします。`L` で命令を確かめられます。
>
> ```
> *E 0300 A9 80 AA A9 00 8A 8D F0 03 8E F1 03 60
> *L 0300 0305
> 0300  A9 80     LDA   #$80
> 0302  AA        TAX
> 0303  A9 00     LDA   #$00
> 0305  8A        TXA
> *G 0300
> *D 03F0 03F1
> 03F0: 80 80 00 00 00 00 00 00 24 F4 24 F4 00 00 00 00
> ```
>
> 最後の `TXA` で、A が `$00` から X の `$80` になります。X は `$80` のままです。

> **Glow65 で確かめられること**
>
> SP を `$F0` にして `TSX` で読みます。`$03E4` に元の SP、`$03E5` に `TSX` で読んだ X、`$03E6` に P を書きます。
>
> ```
> *E 0300 BA 8E E4 03 A2 F0 9A A2 00 BA 08 68 8D E6 03 8E
> *E 0310 E5 03 AE E4 03 9A 60
> *G 0300
> *D 03E4 03E6
> 03E4: FD F0 B4 00 00 00 00 00 00 00 00 00 00 00 00 00
> ```
>
> `$03E4` の `FD` は、書き換える前の SP です。`$03E5` の `F0` が `TSX` の結果で、`$03E6` の `B4` は N が 1 であることを示します。
