# Glow65 マニュアル(日本語)

このマニュアルは、読んで理解するための資料です。6502 の歴史、CPU の仕組み、命令、メモリの使い方を順に説明します。

手を動かして試す資料は、別の場所にある[チュートリアル](../../tutorial/README.ja.md)です。チュートリアルは、短いプログラムを Glow65 に入れて動かし、LED とモニタで結果を確かめます。マニュアルは、その背景にある考え方と仕様を扱います。どちらを先に読んでもかまいません。
